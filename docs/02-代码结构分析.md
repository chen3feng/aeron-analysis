# 代码结构分析

## 1. 项目概览

Aeron 使用 **Gradle** 构建系统，代码以 **Java** 为主（~9 万行），**C** 为独立客户端/驱动实现（~4 万行），**C++** 提供示例和性能测试。

```
aeron/
├── build.gradle              # 根构建脚本（Java 21+，shadow plugin）
├── settings.gradle           # 11 个子模块注册
├── version.txt               # 版本号（如 1.46.9）
├── gradlew / gradlew.bat     # Gradle Wrapper
├── CMakeLists.txt            # C/C++ 构建入口（顶层 CMake）
├── cppbuild                  # C/C++ 构建脚本
│
├── aeron-client/             # ★ 客户端 API（Java + C）
│   └── src/main/
│       ├── java/io/aeron/    # Java 客户端实现
│       └── c/                # C 客户端实现（独立）
│
├── aeron-driver/             # ★ Media Driver（Java + C）
│   └── src/main/
│       ├── java/io/aeron/driver/
│       │   ├── media/        # UDP 传输层
│       │   ├── buffer/       # 日志存储
│       │   ├── status/       # 状态指标
│       │   └── ext/          # 扩展点
│       └── c/                # C 驱动实现（独立）
│
├── aeron-archive/            # ★ 流持久化与回放
│   └── src/main/
│       ├── java/io/aeron/archive/
│       └── c/client/         # C Archive 客户端
│
├── aeron-cluster/            # ★ Raft 共识集群
│   └── src/main/java/io/aeron/cluster/
│
├── aeron-agent/              # ★ 事件日志与监控
│   └── src/main/java/io/aeron/agent/
│
├── aeron-samples/            # 示例程序（Java/C/C++）
│   └── src/main/
│       ├── java/io/aeron/samples/
│       ├── cpp/              # C++ 示例（Ping/Pong/Throughput）
│       └── c/                # C 示例
│
├── aeron-system-tests/       # 系统集成测试
├── aeron-test-support/       # 测试工具类
├── aeron-annotations/        # 自定义注解（@Versioned）
└── aeron-all/                # 合并发布 JAR
```

## 2. 模块依赖关系

```
                    ┌────────────────┐
                    │ aeron-all      │  ← uber JAR (shadow plugin)
                    └───────┬────────┘
                            │ 聚合发布
        ┌───────────────────┼────────────────────┐
        │                   │                    │
  ┌─────▼──────┐   ┌────────▼───────┐   ┌───────▼────────┐
  │ aeron-     │   │ aeron-archive  │   │ aeron-cluster  │
  │ samples    │   │                │   │                │
  └─────┬──────┘   └───────┬────────┘   └───────┬────────┘
        │                   │                    │
  ┌─────▼──────┐           │           ┌────────▼────────┐
  │ aeron-     │◄──────────┼───────────┤ aeron-agent     │
  │ client     │           │           │ (拦截器+日志)    │
  └─────┬──────┘           │           └─────────────────┘
        │                   │
  ┌─────▼──────┐   ┌───────▼────────┐
  │ aeron-     │   │ aeron-archive  │
  │ driver     │   │ (使用client+   │
  └────────────┘   │  driver)       │
                   └────────────────┘
```

核心依赖链：

- `aeron-driver` → `aeron-client`：驱动使用客户端定义的协议和 log buffer 结构
- `aeron-archive` → `aeron-client` + `aeron-driver`：Archive 是驱动功能的一个客户端
- `aeron-cluster` → `aeron-client` + `aeron-driver` + `aeron-archive`：集群使用所有下层模块
- `aeron-agent` → `aeron-client` + `aeron-driver`：监控拦截所有组件事件

## 5. 构建系统

### 5.1 Gradle（Java 构建）

根脚本 [build.gradle](aeron/build.gradle) 定义：

- Java 版本：通过 `BUILD_JAVA_VERSION` 环境变量或当前 JDK
- 版本号：从 `version.txt` 读取
- 子模块版本：`aeronVersion`

模块构建由各子模块的独立 `build.gradle` 控制：

- `aeron-client` 和 `aeron-driver` 生成独立 JAR
- `aeron-all` 通过 Gradle Shadow plugin 合并所有模块为一个 uber JAR

### 5.2 CMake（C/C++ 构建）

顶层 [CMakeLists.txt](aeron/CMakeLists.txt) 管理 C 客户端、C 驱动、C++ 示例的编译：

- `BUILD_AERON_DRIVER` — 是否构建 C 驱动
- `BUILD_AERON_ARCHIVE_API` — 是否构建 Archive C 客户端
- `AERON_TESTS` — 是否构建测试

构建脚本在 `cppbuild` / `cppbuild.ps1` 中封装，自动下载 Google Test、HdrHistogram 依赖。

### 5.3 版本管理

版本号存储在 [version.txt](aeron/version.txt)，由 Gradle 和 CMake 分别读取，保证 Java 和 C 版本一致。

## 6. 测试体系

| 模块 | 测试类型 | 说明 |
|------|---------|------|
| `aeron-client` | Unit Test | 核心 API、协议编码、LogBuffer 测试 |

| `aeron-system-tests` | Integration Test | 端到端 IPC/UDP 测试、Archive、Cluster |

| C tests | Unit Test (Google Test) | C 客户端和驱动独立测试 |

## 7. 关键设计决策

| 决策 | 说明 |
|------|------|
| **Java + C 双语言独立实现** | 共享协议定义，各自独立实现，无 JNI 依赖 |
| **模块拆分精简** | 仅 11 个 Gradle 模块，职责清晰 |
| **aeron-all Uber JAR** | 通过 Shadow Plugin 合并，方便分发 |
| **CMake 与 Gradle 并行构建** | C 构建不依赖 Java 构建 |
| **system-tests 独立模块** | 端到端测试独立于单元测试 |
